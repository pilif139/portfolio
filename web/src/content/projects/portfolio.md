# Portfolio

My personal portfolio website — a space to showcase my experiences and myself. Each project entry is written up like a small case study, and the site is designed to grow with me: it can later be extended into a blog or a bigger personal site.

## About this project

The app itself is statically generated by [Astro](https://astro.build), and deployed for free on [GitHub Pages](https://pages.github.com). I made it that way so I could get a free domain and hosting without any additional setup. The statically generated pages describing my projects are synchronized with my GitHub repositories using a custom script. That way I will also need to keep other repos README's well written and up to date.

## Tech stack

- [Astro](https://astro.build) — content-focused static site generator; easy to extend into a blog later
- [TypeScript](https://www.typescriptlang.org) — for type safety
- [Tailwind CSS](https://tailwindcss.com) — styling
- Deployed for free on [GitHub Pages](https://pages.github.com)
